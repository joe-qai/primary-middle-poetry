# 墨韵 · 中小学古诗词全集

面向 K12 学生（参照人教版统编语文教材）的古诗词、文言散文、典故故事与课外篇学习站。纯静态单页应用，含难字拼音、译文、赏析与考点，支持 H5 横向顺滑浏览与学习进度记录。

## 功能

- **难字注音**：以 ruby 注音逐字标注生僻字、易读错字，多音节词拆到每个字上，避免"张冠李戴"
- **重点句加粗**：考试高频诗句整行加粗；文言文按句定位、句内加粗，不打断整段阅读
- **正文朗读**：每篇详情页可一键朗读，顺序为**标题 → 朝代 → 作者 → 正文**。优先播放仓库内预生成的 MP3（华为自带浏览器、微信内置浏览器、QQ/UC、iOS Safari、PC 全平台可用），音频缺失或加载失败时自动退回浏览器系统语音；支持暂停 / 继续、逐句高亮跟读，切换篇目或关闭时自动停止
- **H5 横向滑动**：移动端卡片左右顺切浏览，整页控制在两屏以内
- **H5 阅读字号**：移动端整体字号放大一档；诗行按屏宽自动缩放，七言等长句不会在末字折行
- 全站搜索：按标题、作者、诗句、译文检索，范围覆盖全部 308 条（诗词 / 散文 / 故事 / 课外 / 名篇 / 诗人组合），结果分组展示、标题命中优先
- **学习进度**：点击「标记已学」，进度保存在浏览器 localStorage
- **详情导航**：上一篇 / 下一篇顺次翻阅，支持键盘方向键与 Esc
- **诗人组合**（新增）：九组诗词流派聚合页——三曹、建安七子、竹林七贤、初唐四杰、唐宋八大家、三苏、大李杜、小李杜、苏辛。每个群体卡片列出成员姓名与篇目数，点击进入后按作者分组展示所有关联篇目，点击篇目可跳转详情并朗读。

## 技术

- 纯静态：`index.html` + `data.js`，无需构建
- **运行时零外部依赖**：不引用任何 CDN / 外链字体，只请求本站的 `data.js`、`audio/index.json` 与按需的音频文件；国内网络（华为 / 微信内置浏览器）不会因外链阻塞而白屏
- 字体走系统字体栈（思源宋体 / 宋体 / 苹方 / 微软雅黑），无 Web Font 下载
- 数据与视图分离，新增内容只需编辑 `data.js`
- 拼音标注语法：`字{pīn}`，例如 `曲{qū}项{xiàng}向天歌`

### 数据结构

```js
{
  id: 'p001',
  title: '咏鹅',
  dynasty: '唐',
  author: '骆宾王',
  level: 'primary',   // primary | middle
  grade: '一年级上',
  tag: '动物',
  pinyin: '鹅{é}，鹅{é}，鹅{é}，曲{qū}项{xiàng}向天歌。',
  translation: '……',
  analysis: '……',
  points: ['考点一', '考点二']
}
```

散文 / 故事 / 名篇馆使用 `content`（正文）、`translation`、`analysis`、`meaning`、`points` 字段。

## 朗读音频

朗读采用「预生成音频优先 + 系统语音兜底」，**运行时不访问任何外部服务**：

```
audio/
├── index.json      # 已生成篇目清单（前端据此判断是否走音频）
├── p001.mp3        # 单篇音频，按需加载
├── p001.json       # 逐句时间轴，用于高亮跟读
└── …               # 294 篇全量，约 83 MB
tools/
└── gen_audio.py    # 本地一次性生成脚本（edge-tts）
```

当前已覆盖**全部 308 条**（诗词 195 / 散文 34 / 故事 26 / 课外 29 / 名篇 24），总时长约 270 分钟、音频合计约 95 MB。新增篇目后重新跑一次 `--all` 即可，已存在的文件会自动跳过。

生成命令（开发机联网一次，产物提交进仓库即可）：

```bash
pip install edge-tts

python tools/gen_audio.py --ids p001,w001,c001   # 指定篇目
python tools/gen_audio.py --kind poem --level primary
python tools/gen_audio.py --all                  # 全量
python tools/gen_audio.py --ids p001 --force     # 覆盖重生成
```

- 音色：`zh-CN-YunjianNeural`（云健，浑厚男声），语速 `-10%`；《咏鹅》这类活泼童诗单独用 `zh-CN-YunxiNeural`（云希，明亮年轻男声）正常语速，见脚本内 `SPEECH_OVERRIDES`
- 「鹅，鹅，鹅」：edge-tts 的列举语调会把三个字读成降调（像「饿」）。脚本改成先合成载体句「鹅的毛」，按能量切出模型自己读出的自然第二声（约 140→200Hz），再轻微变调复制三份拼回全篇，见 `EXPR_OPENINGS` 的 `carrier` 模式
- 输出 MP3 为 24kHz / 48kbps 单声道，逐句时间轴来自 edge-tts 的 `SentenceBoundary`
- 「而」在长句连读中容易被引擎吞掉：前文连续 6 字以上时脚本会自动补一个停顿逗号，**只影响音频，不改页面文本**
- 专名多音字走 `PRONOUNCE` 映射：送进 TTS 前换成同音字，读完后把字幕时间轴还原成原文，例如「张僧繇」按 `张僧由` 合成（繇 yóu），页面仍显示「张僧繇」
- 教材古读同样走 `PRONOUNCE`，且一律带上下文（如「亡赖」→「无赖」、「朝奏」→「招奏」、「会稽」→「快基」），只改送进 TTS 的文本，页面注音与正文都不变；键值字数必须相同，否则时间轴会错位，脚本在加载时会做校验
- 音频地址带内容版本号 `?v=<hash>`，重新生成后不会被浏览器或 CDN 缓存住
- 前端音频地址统一走 `index.html` 里的常量 `AUDIO_BASE`，将来迁 CDN 只改这一行
- 尚未生成的篇目会自动使用 Web Speech API，因此不会出现「点击无反应」
- 音频通过 `fetch` 读取清单，**直接双击 `index.html`（file://）时朗读会退回系统语音**，需要 HTTP 服务才能启用音频
