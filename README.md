# 墨韵 · 中小学古诗词全集

面向 K12 学生（参照深圳 2026 统编语文课标）的古诗词、文言散文、典故故事与课外篇学习站。纯静态单页应用，含难字拼音、译文、赏析与考点，支持 H5 横向顺滑浏览与学习进度记录。

## 在线访问

https://joe-qai.github.io/primary-middle-poetry/

合计 **286 条**内容。全部篇目均为**全文**（不再收录节选）。每条均包含：**原文（难字拼音）→ 译文 → 赏析 → 考点**（散文、名篇馆为：正文 → 译文 → 赏析 → 考点；故事为：故事 → 寓意 → 考点）。

## 功能

- **难字注音**：以 ruby 注音逐字标注生僻字、易读错字，多音节词拆到每个字上，避免"张冠李戴"
- **重点句加粗**：考试高频诗句整行加粗；文言文按句定位、句内加粗，不打断整段阅读
- **正文朗读**：每篇详情页可一键朗读，顺序为**标题 → 朝代 → 作者 → 正文**；中文男声，按标点断句留白，疑问上扬、感叹提气、句读放缓，重点句再放慢；支持暂停 / 继续，切换篇目或关闭时自动停止
- **H5 横向滑动**：移动端卡片左右顺切浏览，整页控制在两屏以内
- **搜索与筛选**：按标题、作者、诗句、译文检索，支持小学/初中筛选
- **学习进度**：点击「标记已学」，进度保存在浏览器 localStorage
- **详情导航**：上一篇 / 下一篇顺次翻阅，支持键盘方向键与 Esc

## 技术

- 纯静态：`index.html` + `data.js`，无需构建
- 数据与视图分离，新增内容只需编辑 `data.js`
- 拼音标注语法：`字{pīn}`，例如 `曲{qū}项{xiàng}向天歌`

### 数据结构

```js
{
  id: 'p001',
  title: '咏鹅',
  dynasty: '唐',
  author: '骆宾王',
  level: 'primary',   // primary | middle
  grade: '一年级上',
  tag: '动物',
  pinyin: '鹅{é}，鹅{é}，鹅{é}，曲{qū}项{xiàng}向天歌。',
  translation: '……',
  analysis: '……',
  points: ['考点一', '考点二']
}
```

散文 / 故事 / 名篇馆使用 `content`（正文）、`translation`、`analysis`、`meaning`、`points` 字段。
