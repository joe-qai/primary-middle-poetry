# 墨韵 · 中小学诗歌全集

面向 K12 学生（参照人教版统编语文教材）的诗歌、散文、课外篇与国外诗学习站。纯静态单页应用，含难字拼音、译文、赏析与考点，支持 H5 横向顺滑浏览与学习进度记录。涵盖中国古代诗词、现代诗歌、国外诗歌及文言散文。

## 功能

- **难字注音**：以 ruby 注音逐字标注生僻字、易读错字
- **重点句加粗**：考试高频诗句整行加粗；文言文按句定位、句内加粗，不打断整段阅读
- **正文朗读**：每篇详情页可一键朗读，顺序为**标题 → 朝代 → 作者 → 正文**。优先播放仓库内预生成的 MP3（华为自带浏览器、微信内置浏览器、QQ/UC、iOS Safari、PC 全平台可用），音频缺失或加载失败时自动退回浏览器系统语音；支持暂停 / 继续、逐句高亮跟读，切换篇目或关闭时自动停止
- **H5 横向滑动**：移动端卡片左右顺切浏览，整页控制在两屏以内
- **H5 阅读字号**：移动端整体字号放大一档；诗行按屏宽自动缩放
- 全站搜索：按标题、作者、诗句、译文检索，范围覆盖全部板块，结果分组展示、标题命中优先
- **学习进度**：点击「标记已学」，进度保存在浏览器 localStorage
- **详情导航**：上一篇 / 下一篇顺次翻阅，支持键盘方向键与 Esc
- **名人馆**：九组诗词流派聚合页——三曹、建安七子、竹林七贤、初唐四杰、唐宋八大家、三苏、大李杜、小李杜、苏辛。每个群体卡片显示简介、成员姓名与关联篇目数，点击进入后按作者分组展示所有作品，点击篇目可跳转详情并朗读。

## 技术

- 纯静态：`index.html` + `data.js`，无需构建
- **运行时零外部依赖**：不引用任何 CDN / 外链字体，只请求本站的 `data.js`、`audio/index.json` 与按需的音频文件
- 字体走系统字体栈（思源宋体 / 宋体 / 苹方 / 微软雅黑），无 Web Font 下载
- 数据与视图分离，新增内容只需编辑 `data.js`
- 拼音标注语法：`字{pīn}`，例如 `曲{qū}项{xiàng}向天歌`

### 数据结构

```js
{
  id: 'p001',
  title: '咏鹅',
  dynasty: '唐',
  author: '骆宾王',
  level: 'primary',   // primary | middle | highschool
  grade: '一年级上',
  tag: '动物',
  pinyin: '鹅{é}，鹅{é}，...',
  translation: '……',
  analysis: '……',
  points: ['考点一', '考点二']
}
```

各数组说明：
- `poems`: 中小学教材诗歌（含 primary / middle / highschool 三个级别）
- `foreign_poems`: 国外诗歌（留空待填充）
- `prose`: 文言散文
- `extras`: 课外拓展篇目
- `classics`: 课标名篇全文
- `figures`: 名人馆（作家群体，含人物简介 bio 与成员作品列表 members.items[]）

## 朗读音频

朗读采用「预生成音频优先 + 系统语音兜底」，**运行时不访问任何外部服务**：

```
audio/
├── index.json      # 已生成篇目清单（前端据此判断是否走音频）
├── p001.mp3        # 单篇音频，按需加载
├── p001.json       # 逐句时间轴，用于高亮跟读
└── …               # 全量音频
tools/
└── gen_audio.py    # 本地一次性生成脚本（edge-tts）
```

当前已覆盖**全部诗词、散文、课外、名篇**，总时长约 320 分钟。新增篇目后重新跑一次 `--all` 即可，已存在的文件会自动跳过。

生成命令：

```bash
pip install edge-tts

python tools/gen_audio.py --ids p001,w001,c001   # 指定篇目
python tools/gen_audio.py --kind poem --level primary
python tools/gen_audio.py --all                  # 全量
python tools/gen_audio.py --ids p001 --force     # 覆盖重生成
```

- 音色：`zh-CN-YunjianNeural`（云健，浑厚男声），语速 `-10%`
- 「鹅，鹅，鹅」等特殊发音通过 `SPEECH_OVERRIDES` 处理
- 输出 MP3 为 24kHz / 48kbps 单声道，逐句时间轴来自 edge-tts 的 `SentenceBoundary`
- 专名多音字走 `PRONOUNCE` 映射：送进 TTS 前换成同音字，读完后还原时间轴
- 教材古读同样走 `PRONOUNCE`，键值字数必须相同，否则时间轴会错位
- 音频地址带内容版本号 `?v=<hash>`，重新生成后不会被浏览器或 CDN 缓存
- 前端音频地址统一走 `index.html` 里的常量 `AUDIO_BASE`
- 尚未生成的篇目会自动使用 Web Speech API
- **直接双击 `index.html`（file://）时朗读会退回系统语音**，需要 HTTP 服务才能启用音频

## 本地预览

直接双击 `index.html`，或启动静态服务器：

```bash
python -m http.server 8080
# 访问 http://localhost:8080
```
